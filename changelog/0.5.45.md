# 0.5.45 - 2026-11-26

- The memory guard follows the host instead of a fixed 1 GiB. It is an eighth of the physical memory
  the runtime reports, with a 1 GiB floor, read on every check, so a 331 MB map that projects to
  2.9 GiB opens on a large machine and a small one still opens a map. `WC3_MCP_MEMORY_BUDGET`
  overrides it, in bytes with an optional K, M or G suffix, and a value that does not parse leaves
  the derived budget in force rather than opening the guard or closing it at zero. The refusal names
  the budget that applied and whether it came from the host or the variable.
- Every decode in `Wc3.Render` goes through `SafeImages`, which holds the one decoder configuration,
  with a test per entry point. The four TIFF and ICC advisories against ImageSharp 3.1.12 are only
  fixed in 4.1.1, and that line refuses to build without a licence key, so the pinned version stays
  and those paths stop being reachable. The same rule found a decoder that was never disposed and it
  was fixed in place.
- The four scripts under `docs/reforged-3.0.0-evidence` read the game data folder through
  `tact.game_data_dir()`, which takes `WC3_DATA` first and then the folder each platform installs
  into, instead of the literal `C:/Warcraft III/Data`.
- The npm launcher checks the platform first and says plainly that the package ships the Windows
  build, rather than dying inside `tar.exe` and then inside a PowerShell fallback that macOS does not
  have.
- The fuzz watchdog keeps its second plus grace for a case that never returns, and the elapsed check
  carries its own four second ceiling. A two core runner pays a first case JIT cost that landed a
  healthy kilobyte parse past the one second budget and read as a hang.
- House punctuation is applied across the comments and documents that carry prose, mechanically
  rather than by hand, and a range between two numbers reads as `to`. The linter then proved the
  result. Generated reference pages, vendored docs, release notes and the skill documents that ship
  in two copies are named in `.slopignore` with their reason instead.
- The lint findings were cleared at their cause. The evidence harness writes JSON rather than a
  pickle cache, split into load and save so a lost update cannot happen between them, six asserts
  became raises carrying the same message, the analyzer records the rows it cannot read instead of
  dropping them, and every magic number the tests compare against is a named constant.
- The release notes are linted rather than skipped. Sixteen of them opened with `# version` and then
  `### Added`, which skips a level, so those subheads read as `##` now.
- The watch command is split into reading and rendering, the step reports are named and asserted, and
  the fence closers in the documents are fixed so a rendered page is not one long code block.
- The 7z import archive, the audio dump and the audit files this machine keeps are ignored rather
  than committed.

Version 0.5.45.
